# 部署上线清单

本文档用于把当前版本从开发环境推进到生产环境。代码侧已完成 `go build -tags pro ./...`、前端生产构建与 PostgreSQL 全量验收；下列步骤需要部署环境、微信商户参数和数据库凭据。

## 1. 构建产物

```bash
# 后端（生产标签）
go build -tags pro -o app .

# 前端小程序
pnpm --dir minifront install
pnpm --dir minifront type-check
pnpm --dir minifront test:sdui
pnpm --dir minifront build:weapp
```

产物：

- 后端二进制 `app`（或按 `Dockerfile` 构建镜像）；
- 小程序产物 `minifront/dist/`，通过微信开发者工具上传。

## 2. 必填环境变量

| 变量 | 说明 |
| --- | --- |
| `APP_ENV=production` | **必须显式设置**；否则支付沙箱接口会按开发环境开放 |
| `DB_DRIVER` | `mysql` 或 `pg` |
| `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` | 生产数据库连接 |
| `PUBLIC_BASE_URL` | 对外 HTTPS 根地址，用于微信支付回调 `https://<host>/api/v1/payment/notify/<app_id>` |
| `JWT_SECRET` | ≥16 位，多副本必须一致 |
| `ADMIN_JWT_SECRET` | ≥16 位，多副本必须一致 |
| `CSRF_SECRET` | ≥16 位，v1.0.8 起生产启动强校验 |
| `MCP_AUTH_KEY` | ≥16 位；HTTP MCP 调用密钥 |
| `COS_SECRET_ID` / `COS_SECRET_KEY` / `COS_BUCKET_URL` | 生产启动会校验 COS 配置 |
| `COS_CDN_URL` | 可选，图片 CDN 根地址 |
| `REDIS_PASSWORD` | 开启 Redis 时必填 |
| `HTTP_RATE_LIMIT_PER_MINUTE` | 可选，全站限流，默认 600 |
| `DB_MAX_OPEN_CONNS` / `DB_MAX_IDLE_CONNS` | 可选，连接池，默认 30 / 10 |
| `MCP_ALLOWED_TENANTS` | 可选，MCP 租户白名单 |

`DEFAULT_MINIAPP_APP_ID` / `DEFAULT_MINIAPP_APP_SECRET` 仅用于首次启动自举默认小程序；已有 `mini_apps` 数据时不需要设置。

## 3. 数据库迁移

启动时 `system.Migrate()` 会执行 GORM AutoMigrate。本版本相对上一版新增：

- `payment_orders.kind`、`payment_orders.items`、`payment_orders.coupon_id`、`payment_orders.discount_fen`；
- `domain_records.rating`。

步骤：

1. 备份生产库；
2. 在 staging 副本执行一次新版本启动，确认 AutoMigrate 成功、表锁时间可接受；
3. 生产发布窗口执行启动；
4. 校验列与索引：

```sql
-- MySQL
SHOW COLUMNS FROM payment_orders LIKE 'kind';
SHOW COLUMNS FROM payment_orders LIKE 'coupon_id';
SHOW COLUMNS FROM domain_records LIKE 'rating';

-- PostgreSQL
\d payment_orders
\d domain_records
```

数据库验收（MySQL 或 PostgreSQL 临时库）：

```bash
ACCEPTANCE_DB=mysql DB_HOST=... DB_PORT=... DB_USER=... DB_PASSWORD=... \
  go test ./services -run TestLocalDatabaseAcceptance

ACCEPTANCE_DB=pg DB_HOST=... DB_PORT=... DB_USER=... DB_PASSWORD=... \
  go test ./services -run TestLocalDatabaseAcceptance
```

## 4. 微信配置

1. 在小程序后台把 `PUBLIC_BASE_URL` 域名加入 `request` 合法域名与业务域名；
2. WebView 使用的 `url_key` 对应域名必须加入业务域名；
3. 每个 `mini_apps` 行配置微信支付商户号、证书序列号、APIv3 密钥、私钥，并确认支付回调地址可访问；
4. 上传 `minifront/dist` 为新版本，先体验版验收再全量发布；
5. `RootPortal` 依赖微信基础库 ≥2.19.4（当前开发库 3.17.2）。

## 5. 发布后冒烟

- `GET /healthz` 返回 `{"status":"ok","db":"ok"}`；
- 首页 `GET /api/v1/page/home` 200，主题/字号/块级错误边界正常；
- 分享好友与朋友圈：公开页可打开；AI 文章分享给未登录用户显示登录提示；`owner` 页非分享者显示“仅分享者本人”；
- WebView：`web-view src` 含 `sdui_font_size/sdui_font_scale/sdui_theme`，登录失效时显示提示；
- 商品单 SKU 支付：真实微信支付最小金额一笔，确认 `notify → order.confirm → 权益发放`；
- 购物车多 SKU：`cart.quote` 金额与 `payment/orders` 服务端金额一致，支付成功生成 `order.list` 可见订单；
- 优惠券：领取 → 支付抵扣 → 退款恢复可用；
- 评价：已完成订单提交一条评价，公开列表可见；
- 管理/MCP：`sdui.production.readiness`、`sdui.domain.list`、`sdui.domain.execute` 权限正常。

## 6. 回滚

- 镜像回滚到上一版本；
- 本版本数据库变更为**加列**，旧版本可忽略新列，无需立即回滚数据库；
- 若需回滚前端，上传上一版小程序代码；
- 优惠券/订单新功能回滚前先停止新支付入口，避免产生旧版本无法识别的购物车订单。

## 7. 当前已知边界

- 购物车不能混入会员/文章权益 SKU（会提示“请单独购买”）；
- 真实微信支付、MySQL 实例需在 staging 完成最后一轮验证；
- 弹层 safe-area/键盘遮挡仍需真机复验；
- 优惠券定义与回收目前走 MCP/管理域操作，没有独立可视化后台。
