# 验收问题与修复记录

## 已补实际执行证据

证据：acceptance/results.json；复现：`node scripts/acceptance-evidence.mjs`。独立数据库测试只接受 development 配置，在配置的数据库服务上新建随机命名的 hk_acceptance_* 数据库，结束后删除该测试库，不写入已有业务库。不记录密码或完整 DSN。

| 验收项 | 测试位置 | 边界 |
| --- | --- | --- |
| 模板保存、修改、删除及 revision | TestLocalDatabaseAcceptance/模板持久化 | 真实 MySQL；不是仅参数验证 |
| 草稿 CAS 冲突 | TestLocalDatabaseAcceptance/草稿版本冲突 | 顺序模拟两个编辑者持有同一旧版本 |
| 已撤销 refresh token 重放拒绝 | TestLocalDatabaseAcceptance/会话重放 | 不等于前端并发刷新全链路已验收 |
| WebView 注册表隔离 | TestLocalDatabaseAcceptance/WebView租户隔离 | 数据库注册表；微信业务域名审核仍需平台配置 |
| 支付创建幂等、价格、跨租户拒绝、成功/重复回调、退款权益 | TestLocalDatabaseAcceptance/支付回调与退款权益 | 两个真实 AppID 的隔离测试数据；直接调用回调服务，不等于 HTTP 签名验签测试 |
| MCP 创建、get、patch、validate、preview、publish、set_current、revisions、跨租户拒绝 | TestLocalDatabaseAcceptance/双租户MCP草稿发布闭环 | 调用实际 MCP 服务及真实数据库；尚未覆盖全部 HTTP 传输和全部工具业务操作 |
